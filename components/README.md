# components/ — do not use as a design kit

PromptWeb **no longer ships HTML component samples** for AI to assemble.

**Why:** stacking sample heroes/features/CTAs made every site look similar.

**What to do instead:**
1. Read `AI_INSTRUCTIONS.md` / `README.md`.
2. Invent **original** section HTML for the user’s industry (jewellery, fitness, restaurant, …).
3. Every marketing page needs **15+ unique section designs**.
4. Research-style inspiration: Dribbble, Behance, Pinterest, Awwwards — rebuild in Tailwind; never copy assets.
5. **No mandatory theme switcher.** Hardcode a page-specific palette.

If old `components/*.html` files still exist in this folder from an earlier Initialize, **ignore them**.
